# Jogo da Forca em C++

Jogo da Forca desenvolvido em C++ para execução em terminal.

## Funcionalidades
- Menu interativo (Jogar, Sobre, Sair)
- Sorteio aleatório de palavras
- Sistema de tentativas e controle de erros
- Desenho progressivo da forca conforme erros
- Validação de letras digitadas pelo jogador
- Condições de vitória e derrota

## Tecnologias e conceitos
- C++
- Estruturas condicionais
- Laços de repetição
- Lógica de programação
- Geração de números aleatórios (`rand`, `srand`)
- Entrada e saída via terminal
